# 🏁 Project CarTuneRacing 2D
### เกมแต่งรถ จูนเครื่องยนต์สมจริง & แข่งแดร็กทางตรง 402m (Singleplayer vs Bots & Real-Time Multiplayer)

โปรเจกต์เกม Web-based 2D Pixel Art สไตล์ Retro Arcade ที่ประมวลผลกราฟิกและฟิสิกส์ **บนเครื่องของผู้เล่นเองโดยตรงผ่าน Canvas 2D & Web Audio API** เซิร์ฟเวอร์จึงมีขนาดเล็กและไม่กินทรัพยากรเครื่อง อีกทั้งยังถูกพัฒนาแบบ **Zero-Dependency (ไม่ต้องติดตั้งแพ็กเกจ npm เสริมแม้แต่ตัวเดียว)** สามารถรันได้ทันทีทั้งออฟไลน์และออนไลน์

---

## 🚀 วิธีเปิดเล่นบนเครื่องตัวเอง
1. ดับเบิลคลิกไฟล์ **`run_game.bat`** (หรือพิมพ์คำสั่ง `node server.js` ใน Terminal)
2. ตัวเกมจะเปิดขึ้นบนเว็บเบราว์เซอร์ที่: **`http://localhost:3000`**
3. สามารถเปิด 2 แท็บ หรือเปิด 2 หน้าต่าง เพื่อทดสอบเล่นแบบ **Multiplayer 1v1** แข่งกันเองบนเครื่องได้ทันที

## 🛠️ ระบบเด่นภายในเกม

### 1. ระบบประกอบรถและเครื่องยนต์แบบโมดูลาร์ (Modular Engine System)
คุณเริ่มต้นจาก **โครงเหล็กถักเปลือย (Tube Chassis)** และต้องเลือกประกอบชิ้นส่วนเองทั้งหมด 17 หมวดหมู่:
* **ตัวถัง (Body):** Coupe, Hatchback, Muscle V8, Carbon Supercar (มีโหมด X-Ray มองทะลุเห็นเครื่องและโครงรถ)
* **บล็อกเครื่องยนต์ (Engine Block):**
  * `2.0L I4 VTEC` (รอบจัด เสียงหวาน ลากได้ถึง 8,800 RPM)
  * `3.0L I6 2JZ` (บล็อกเหล็กหล่อในตำนาน รับบูสต์ได้มหาศาล)
  * `3.5L V6 Twin-Cam` (กำลังสม่ำเสมอทุกย่านรอบ)
  * `5.0L V8 Big-Block` (ทอร์คหนักตั้งแต่ออกตัว เสียงกระหึ่ม)
* **ชิ้นส่วนเครื่องยนต์แยกชิ้น:**
  * ฝาสูบและแคมชาร์ฟท์ (Cylinder Head & Cams)
  * ลูกสูบและก้านสูบ (Pistons & Rods) - **กำหนดขีดจำกัดแรงม้าและบูสต์สูงสุดที่รับได้**
  * แบตเตอรี่และมอเตอร์สตาร์ท (Starter & Battery)
  * ระบบไฟและหัวเทียน (Ignition & Spark Plugs)
  * ระบบน้ำมัน (Fuel Pump & Injectors)
  * หม้อน้ำหล่อเย็น (Cooling Radiator)
  * ระบบอัดอากาศ (Naturally Aspirated, Small Turbo, Massive Drag Turbo, Twin-Turbo, Supercharger)
  * อินเตอร์คูลเลอร์ (Front-Mount Intercooler & Ice Tank)
  * ถังไนตรัสออกไซด์ (50-Shot, 150-Shot Direct Port Drag NOS)
  * ท่อไอเสีย (3-inch Straight Pipe, Hood-Exit Screamer Pipe พ่นไฟทะลุฝากระโปรง)
  * ระบบเกียร์ (4-Speed, 6-Speed Close-Ratio, 5-Speed Sequential Drag Dogbox)
  * ล้อและยาง (Street Radial, Semi-Slick, Drag Slicks 15 นิ้ว)
  * แอโร่ไดนามิกส์ (Ducktail, Drag Wing, Front Splitter)
  * ระบบเบรก (Big Calipers, Drag Parachute ร่มชูชีพหยุดรถ)

### 2. ระบบวินิจฉัยเครื่องยนต์ ECU สมจริง (Diagnostic System)
มีปุ่ม **"🔑 สตาร์ทเครื่องยนต์ (Test Crank)"** ในโรงรถ:
* **หากชิ้นส่วนไม่ครบ:** รถจะสตาร์ทไม่ติด และ ECU จะรายงานความผิดพลาด เช่น:
  * `ECU FAULT #01: ไม่มีแบตเตอรี่ / ไดร์สตาร์ท เครื่องไม่หมุน`
  * `ECU FAULT #02: ไม่มีประกายไฟจุดระเบิด ขาดหัวเทียน/คอยล์`
  * `ECU FAULT #03: ขาดระบบน้ำมันเชื้อเพลิง ไม่มีปั๊มติ๊ก/หัวฉีด`
* **ระบบเตือนความเสี่ยง:**
  * หากไม่มีหม้อน้ำ: เตือนเสี่ยง Overheat ทันที
  * หากหัวฉีดเล็กเกินแรงม้า: เตือนส่วนผสมบาง เสี่ยงเครื่องเขก (Detonation)
  * หากแรงม้าเกินขีดจำกัดก้านสูบ: เตือนเสี่ยงก้านสูบขาด

### 3. ระบบความเสียหายและการระเบิดของเครื่องยนต์ (Engine Damage Model)
* **โอเวอร์ฮีต (Overheating):** หากใช้หม้อน้ำไม่เหมาะสม อุณหภูมิน้ำจะพุ่งเกิน 125°C ส่งผลให้ **ประเก็นฝาสูบแตก ฝาโก่ง ควันขาวพวยพุ่ง และกำลังเครื่องตกเหลือศูนย์!**
* **ก้านสูบขาด (Thrown Rod / Blown Engine):** หากปรับบูสต์เทอร์โบสูงจนแรงม้าเกินขีดจำกัดของลูกสูบและก้านสูบ ก้านจะขาดกระแทกเสื้อสูบจนเกิดการระเบิดพร้อมลูกไฟและเสียงโลหะฟาด
* **วาล์วลอย (Valve Float):** หากแช่รอบเครื่องตัดที่ Redline นานเกิน 2.8 วินาที วาล์วจะลอยกระแทกลูกสูบพัง

### 4. อู่ปรับจูนเครื่องยนต์ ECU & แท่นทดสอบไดโน่ (Dyno Tuner)
ข้อมูลการจูนมาตรฐานรถแข่งจริง:
1. **Air-Fuel Ratio (AFR):** อัตราส่วนผสมน้ำมันกับอากาศ (ค่า 12.2 - 12.8 ให้แรงม้าสูงสุด, ต่ำกว่า 11 น้ำมันหนาไป, เกิน 13.5 เสี่ยงเครื่องเขก)
2. **Ignition Timing Advance:** องศาไฟจุดระเบิด (ปรับไฟแก่เพื่อเพิ่มแรงม้า หรือปรับไฟอ่อนเมื่อฉีดไนตรัส)
3. **Turbo Boost Bar:** ปรับเวสเกตควบคุมแรงดันบูสต์เทอร์โบ (0.4 - 2.8 Bar)
4. **Rev Limiter:** กำหนดรอบตัดเครื่องยนต์ (6,000 - 10,000 RPM)
5. **Two-Step Launch RPM:** กำหนดรอบออกตัวแบบล็อกรอบสะสมบูสต์เทอร์โบพร้อมเสียงไฟแลบปังๆ ที่จุดสตาร์ท
6. **Tire Pressure:** แรงดันลมยาง (18-22 PSI เพื่อให้หน้ายางย่นเกาะถนนตอนออกตัว หรือ 30+ PSI เพื่อวิ่งไหลปลาย)
7. **Final Drive Ratio:** อัตราทดเฟืองท้าย
8. **ปุ่ม RUN DYNO:** เร่งเครื่องทดสอบกราฟแรงม้า (HP Curve) แรงบิด (Torque Curve) และบูสต์จริงพร้อมเสียงเครื่องยนต์

### 5. การแข่งขันแดร็ก 402 เมตร (Drag Strip 1/4 Mile)
* สัญญาณไฟต้นคริสต์มาส (Christmas Tree Lights: Pre-Stage, Stage, Yellow 1-2-3, Green)
* มีระบบตรวจจับ **ฟาวล์ออกตัวก่อนไฟเขียว (Red Light Foul)**
* แข่งขัน 2 เลน พร้อมอัฒจันทร์คนดู ป้ายบอกระยะ 60ft, 330ft, 1/8 mi และซุ้มเข้าเส้นชัย 402m
* **ปุ่มควบคุมการขับขี่:**
  * `W` หรือ `ลูกศรขึ้น` : เหยียบคันเร่ง
  * `Spacebar` หรือ `Shift` : เข้าเกียร์ขึ้น (มีไฟ Shift Light แจ้งเตือนรอบตัด)
  * `S` หรือ `ลูกศรลง` : ลดเกียร์
  * `B` : ล็อกรอบออกตัว 2-Step Anti-Lag
  * `N` : ฉีดไนตรัสออกไซด์ (NOS)
* **ใบรายงานเวลาอย่างเป็นทางการ (Official Drag Time Slip):**
  * แสดงเวลา Reaction Time, 60 FT, 330 FT, 1/8 Mile, 1/4 Mile ET และความเร็วเข้าเส้น Trap Speed (km/h)

### 6. โหมดการเล่น & ระบบเงินเดิมพัน
* **โหมดแข่งกับบอท (Career):**
  1. น้องใหม่หัวใจซิ่ง (Civic Street - เดิมพัน $150)
  2. ช่างเอก อู่ซอยตัน (Silvia S15 Boosted - เดิมพัน $500)
  3. พี่เสือ พระรามเก้า (Supra 2JZ 800HP - เดิมพัน $1,800)
  4. พญาปีศาจ 7 วิ (Twin-Turbo V8 Monster - เดิมพัน $5,000)
* **โหมด Real-time Multiplayer 1v1:**
  * มีระบบล็อบบี้แสดงรายชื่อผู้เล่นออนไลน์
  * สร้างห้องแข่ง กำหนดชื่อห้อง และวางเงินเดิมพันตามต้องการ
  * ระบบแชทสดในล็อบบี้
  * ซิงก์ตำแหน่งรถ ความเร็ว เกียร์ รอบเครื่อง และไฟพ่นท่อผ่าน WebSocket

## 🌐 วิธีนำไป Deploy ขึ้นเว็บไซต์ออนไลน์

### ตัวเลือกที่ 1: เล่นกับเพื่อนโดยเปิดจากเครื่องเราเอง (ฟรี 100% ไม่ต้องเช่า Server)
1. **ใช้ [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/get-started/create-local-tunnel/):**
   * รันคำสั่ง: `cloudflared tunnel --url http://localhost:3000`
   * จะได้ลิงก์ HTTPS สวยงาม ส่งให้เพื่อนเปิดเล่นบนเบราว์เซอร์ได้ทันที
2. **ใช้ [ngrok](https://ngrok.com/):**
   * รันคำสั่ง: `ngrok http 3000`
   * ส่ง URL ที่ได้ให้เพื่อนเข้าเล่นร่วมกัน

### ตัวเลือกที่ 2: Deploy ขึ้น Cloud ให้ออนไลน์ 24 ชั่วโมง
เนื่องจากโปรเจกต์นี้เขียนด้วย Node.js ล้วนแบบ **Zero-Dependency**:
1. **[Render.com](https://render.com/) (แนะนำ - มี Free Tier):**
   * สมัครสมาชิกและเชื่อมต่อ GitHub Repository
   * เลือก **New Web Service**
   * Build Command: *(ปล่อยว่าง)*
   * Start Command: `node server.js`
   * เสร็จแล้วเว็บจะออนไลน์ 24 ชั่วโมงพร้อมรองรับ WebSocket ทันที!
2. **[Railway.app](https://railway.app/) หรือ [Fly.io](https://fly.io/):**
   * รองรับ WebSocket แบบ Low-latency ได้อย่างยอดเยี่ยม เพียง push โค้ดขึ้นไป ตัวระบบจะรัน `npm start` ให้โดยอัตโนมัติ
